# 界面与动画

手牌使用完整显示的横向牌列，牌宽和间距固定，不重叠、不旋转。选中只抬高位置并加描边，
再次点击或按「出牌」确认。屏幕内的牌不会因选中而横移；从「全部手牌」选到屏幕外的牌时，
牌列才滚动到相应位置。同一局中保留现有手牌顺序，新摸到的牌追加到末尾。

牌桌从上至下分为玩家列表、当前牌区、手牌和操作区。玩家列表会滚动到当前出牌者，
桌面底色随有效颜色变化。小屏采用较小的牌面；较大字体、额外的质疑按钮和 UNO 窗口
需要更多空间时，可纵向滚动。

## 动画

- 入口分批淡入、滑入并轻微回弹；按钮按压后回弹。
- 手牌选中抬起，摸牌滑入，出牌后邻牌平滑补位。
- 当前牌以滑入、缩放和回弹切换；回合、手牌数量和出牌方向分别过渡。
- 结算播放一次纸屑动画，结束后停止。

动画使用三次缓动与 `easeOutBack`，通过牌 ID、局数等状态标识触发。
重复收到相同状态不会重播动画。退场中的牌会屏蔽触摸和辅助功能焦点。
应用或系统开启「减少动态效果」时直接呈现最终状态。

## 验证

组件测试覆盖手牌间距、选中时宽度和位置不变、选中牌不被裁切、状态更新不打乱顺序、
增减牌、屏幕外选牌、相同牌面不重播、退场牌不可操作，以及减少动态效果。
布局测试覆盖 320×640、十位玩家、40 张手牌、1.6 倍字体和深浅主题。

另已渲染检查首页、牌桌、选牌、设置、登录、加入牌桌、账户和结算页面。
真实手机上的流畅度、触摸体验和真实牌局仍按 [验收清单](acceptance.md) 手动检查。
