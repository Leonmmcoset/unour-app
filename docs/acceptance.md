# Unour 验收与构建

## 环境与命令

Flutter stable、JDK 17+、Android SDK。iOS 需要 macOS、Xcode 和 CocoaPods。

```sh
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
# macOS:
flutter build ios --no-codesign
```

默认地址 `https://csac.chat/`，开发时可使用
`flutter run --dart-define=API_BASE_URL=https://your-real-server/`。
只连接真实后端，不提供本地试玩、模拟服务器或客户端机器人。

Android 包名及 iOS Bundle ID 是 `chat.csac.unour`。正式发行前配置自己的
Android keystore、iOS Team 和签名；开发签名不用于商店发行。

## 手动真实服务验收（待执行）

以下检查由开发者在手机上手动执行。自动化不注册线上账户、不创建线上房间。
准备两个测试账户及两部手机，避免使用常用账户。

- [ ] 注册、重启应用恢复登录、退出登录、过期会话重新登录。
- [ ] 用户名边界、密码 8/14 个 Unicode 字符边界；密码首尾空格不裁剪。
- [ ] 相册选择 PNG/JPEG、替换头像、恢复默认、超大文件与权限拒绝。
- [ ] 人机选择 1/9 位电脑及四种难度；创建后直接进入牌局，不再次 start。
- [ ] 创建多人房间、复制房间号、另一账户加入、房主开始、显示全部玩家。
- [ ] 自定义规则默认值、依赖开关、数字上下界、目录更新与错误提示。
- [ ] 同色／同数出牌、Skip、Reverse、+2、万能牌与 +4 选色。
- [ ] 摸牌后出牌／过牌、罚牌池、叠加与罚牌反转，以服务端规则为准。
- [ ] +4 质疑成功／失败、最后一张 +4 的延迟结算。
- [ ] UNO 两秒内成功、超时罚一张、不推进回合、网络重试不重复罚牌。
- [ ] 第一次进入不重放旧 UNO；从后台恢复未处理窗口。
- [ ] 局中加入先观战、预约／取消下局、观战者无手牌与回合按钮。
- [ ] 结算投票、撤回、最后一票自动开局、名单变化要求重新同意。
- [ ] 主动退出按弃权、房主转交、解散后其他客户端识别 404。
- [ ] 返回首页保留座位；重启后通过最近房间恢复原座位。
- [ ] 飞行模式、弱网、请求超时、旧版本冲突、连续点击不重复出牌。
- [ ] 房间 token 轮换后旧设备重新加入；账户失效要求重新登录。
- [ ] 320×640 手机、十人房间、40+ 手牌、较大字体、深浅主题。
- [ ] 系统减少动态效果、单独关闭音效和轻震动、前后台切换。
- [ ] Android 安装包真机启动，iOS Xcode 构建及真机启动。

## 行为边界

- 最近房间是本机、按账户隔离的最多 20 条记录；服务端未提供房间列表接口。
- 返回首页和关闭应用不等于退出房间。明确点击退出才弃权。
- 账户 Cookie 与房间凭证在安全存储中；偏好设置不含凭证。
- HTTP 不提供创建房间幂等键。创建响应丢失时不能推测房间号，不自动重发。
- 不实现后台实时运行；回到前台重新读取权威状态。
- Android 平板的新系统可能忽略方向锁定，手机以竖屏交互为验收对象。
- 不包含正式 Logo、背景音乐、通知、链接唤起、排行榜或管理入口。
